# UX başarı metrikleri kütüphanesi (yedek)

Ekibin handbook'taki kütüphanesi verildiyse **onu kullan**; bu dosya yalnızca link yokken yedektir. Çıktıda hangisini kullandığını belirt.

"Odada" sütunu: bir test oturumunda bugün ölçülebilir mi? Ana metrik yalnızca "Evet" olanlardan seçilir.

| Metrik | Tür | Odada | Tipik rol | Not |
|---|---|---|---|---|
| Görev başarısı (task success) | Outcome | Evet | Ana | Görevi yardımsız tamamlayanların oranı |
| Görev süresi (time on task) | Outcome | Evet | Ana / Destek | Yalnızca başarılı denemelerde ölç |
| Çaba skoru (SEQ, 1-7) | Algı | Evet | Ana / Destek | Görev sonrası tek soru |
| Hata sayısı / hata oranı | Davranış | Evet | Guardrail / Destek | Hatanın tanımını önceden yaz |
| Yardım isteme / ipucu sayısı | Davranış | Evet | Guardrail | Moderasyonlu testte |
| İlk tıklama doğruluğu | Davranış | Evet | Destek | Navigasyon değişikliklerinde |
| SUS | Algı | Evet | Destek | Tek ekran için ağır kalabilir |
| Dönüşüm / tamamlama oranı (canlı) | Outcome | Hayır | Destek | Analytics gerektirir |
| Geri dönüş oranı / retention | Outcome | Hayır | Destek | Zamana yayılır, ana metrik olamaz |
| Destek talebi sayısı | Davranış | Hayır | Guardrail | Lansman sonrası |
| Terk oranı (drop-off) | Davranış | Hayır | Guardrail / Destek | Adım bazlı funnel |
| Ekran görüntülenme, tıklama | Output | — | Önerme | Output'tur, ana metrik olamaz |
